# 복지나침반 원본 수집 데이터 (data 브랜치)

`main`의 `pipeline/raw/`에 해당하는 원본 수집 캐시입니다. 사이트 코드는 `main`에 있고, 이 브랜치에는 데이터만 있습니다.
수집 프로그램(GitHub Actions)이 매일 바뀐 것만 받아 이 브랜치에 커밋하므로, 커밋 기록이 곧 수집 이력입니다.

| 폴더 | 원천 | 받는 방식 | 이용 조건 |
|---|---|---|---|
| `gov24/` | 행정안전부 대한민국 공공서비스(혜택) 정보 | 공공데이터포털 OpenAPI | 이용허락범위 제한 없음 |
| `bokjiro/` | 한국사회보장정보원 중앙부처·지자체 복지서비스 | 공공데이터포털 OpenAPI | 이용허락범위 제한 없음 |
| `mohw/` | 보건복지부 지방정부 서비스 메뉴판(통합돌봄) | 누리집 게시 PDF (www.mohw.go.kr) | 공공기관 공표 자료, 출처 표시 |

- `_status.json`·`_budget.json`: 마지막 수집 상태와 그날 쓴 API 호출 수
- 서비스 키 등 비밀값은 들어 있지 않습니다 (수집 때 환경변수로만 사용)
