# 현행 신청 경로와 종료 회차 원본 연결 — 2026-10-23 D회차

이번 회차에서는 고정 검토 범위의 13개 원본과 별도 기관 원본 1개를 대조했다. 그중 기존 미연결 원본 10개와 정읍의 종료 회차 원본 1개를 12개 사업자료–서식 관계로 추가했다. 같은 고흥 통합원본을 출산장려금과 산모건강회복비에 각각 연결하므로 파일 수와 관계 수가 다르다.

작업 대상은 `feat/welfare-forms-census`와 PR #12다. main 병합과 운영 배포는 수행하지 않았다.

대전 원본은 현행 [시행규칙 제22조의5](https://www.law.go.kr/ordinInfoP.do?ordinSeq=2158539)가 지정한다. 신청구분의 전체 자녀 수와 아래 표의 미성년 자녀 기재 지시를 구분했다. 성년 형제가 있다는 이유로 자녀 수에서 제외하지 않으며, 주민등록표 등본과 필요한 가족관계증명서로 확인한다. 같은 모음의 다른 별지 28개를 이 사업의 신청서로 승인한 것은 아니다.

완도는 [현행 조례](https://www.law.go.kr/ordinInfoP.do?ordinSeq=2160269)의 제5조·제5조의4·제6조를 대조했다. 양부모, 부모 모두 사망 시 법정부양자, 전입 시점, 입양·재혼 가정의 이전자녀 관계·동일 세대 조건을 반영했다. 돌맞이 원본 뒷면의 이전자녀 거주 확인 문구와 기산점이 현행 조례를 충분히 반영하지 않는 사실은 `sourceIssues`와 화면 조건에 남겼다. 그 확인란은 담당공무원 처리란이며 원본 바이트를 수정하지 않았다.

고흥은 [현행 조례 제6조와 제14조](https://www.law.go.kr/ordinInfoP.do?ordinSeq=2157025)가 같은 별지1을 지정한다. 지방서비스 예시를 고흥의 완성된 전용 항목으로 표시하지 않고 기재 확인이 필요한 통합서식으로 제공한다. 산모건강회복비는 별표2 실물의 산후조리비 유형·금액을 정확한 정부24 사업과 대조한 뒤 추가했다. 별도 분만의료비 최대50만원이나 국비 바우처 환급에 이 연결을 확대하지 않는다.

종전 광주·전남 서식은 [통합특별시 설치 특별법 부칙 제10조제1항과 제14조](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=291147)의 구지역 법규·서비스 존속과 현행 조례의 정확한 별지 지정을 대조했다. 종전 기관명 문서의 60일 간주기간을 연장한 판단이 아니다. 광주 5개 구와 종전 전남 도급여 부분을 각각 조건에 명시했다. 출생기본소득 소급은 최초 신청 지연이나 전출기간에 일반적으로 허용하는 설명이 아니며, 제7조제1항제2~5호의 중단사유 해소·위원회 심의·필요 인정 경로에 한정한다.

정읍은 [공식 2026 모집 공고](https://www.jeongeup.go.kr/board/view.jeongeup?boardId=BBS_0000012&dataSid=1395754)가 직접 배포한 HWPX다. 모집은 2025-12-17~12-30에 종료됐고 지원기간은 2026년 2~12월이다. 기존 제목·조건 표시로 종료 회차임을 다운로드 전에 알리며 화면 작성은 열지 않는다. 옛 `ordin-19617443`의 시60%·학원30% 문구를 승인하거나 그 원본을 자동으로 `covered_by_existing` 처리하지 않았다.

## 원본·작성기·화면 검증

채택한 원본 11개를 실제 한글로 출력한 49쪽을 확인했다. 대전 모음 30쪽은 전체 배치로 확인하고 적용할 21~22쪽은 원래 크기로 다시 보았다. 나머지 19쪽도 모두 확인했다. 원본의 모든 본문 섹션과 SHA를 대조했으며 원문은 변경하지 않았다.

새 HWP 5개는 변환 후 원본과 본문·쪽 수·렌더 픽셀이 모두 같았다. 전체 검증된 변환은 2,497개·4,265쪽이다. 현재 일부 입력을 제공하는 작성 매니페스트는 1,218개이며 모든 칸을 완성할 수 있다는 의미가 아니다.

완도 출산 통합서식은 매니페스트 총 슬롯109칸 중106칸이 열려 있었다. 담당기관 성격22칸 중 접수번호·접수일자2칸은 정상 잠금이며, 나머지 담당공무원 확인20칸과 다른 급여13칸이 열려 있었다. 최초 D집계는 전체 슬롯을 열린 슬롯으로 혼동했으며, E회차에서 제거 전 매니페스트 SHA와 같은 결과를 실제 변환기록으로 재구성해 바로잡았다. 승인한 완도 선택칸 5개는 지원되지만 범위 밖 칸도 함께 열리므로 정확한 원본 ID·SHA에 작성 보류를 추가했다. 원본 다운로드와 검증된 변환본은 유지한다. 다른 원본의 같은 문제까지 모두 수정했다고 설명하지 않는다.
