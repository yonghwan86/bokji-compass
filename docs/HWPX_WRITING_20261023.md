## 파일 생성 방식과 개인정보·원문 보존

작성기는 빈 공개 서식만 GET으로 받아오고, 입력값은 브라우저의 현재 React 상태와 다운로드용 Blob에서 처리한다. `PaperFormWriter`에는 작성값을 서버·MCP·AI에 업로드하거나 영구 저장하는 요청이 없다. 다운로드 주소는 해제하며, 작성 내용으로 전자서명이나 신청 접수를 대신하지 않는다.

입력 위치는 실제 XML의 section·표·행·열·문단 및 문자 범위다. 저장 전에 원문 문자열, 삽입 위치의 `charPrIDRef`, 언어별 글꼴·크기·비율·자간과 측정 가능한 문자 폭, 원본·asset·manifest SHA를 대조한다. 모르는 글꼴이나 문자 폭은 임의 추정하지 않는다. 표·문단 수를 재검사하고 승인된 범위만 교체하여 HWPX ZIP을 브라우저에서 다시 만든다. 같은 문단의 복수 입력도 실제 문자 범위와 스타일에 맞춰 처리한다.

선택하지 않은 법률 문구·수신자·서식 본문·스타일·표와 리소스는 보존한다. 이번 확대의 서명·동의체크·기관 확인 부분은 잠금 또는 사업별 허용 목록에서 제외한다. 작성 후 `PrvText`는 새 본문으로 재생성하고, 빈 원본의 오래된 미리보기 그림은 XML/HPF 참조가 없는 경우에만 제거한다. 브라우저의 표 미리보기나 글리프 폭 계산은 한글의 최종 페이지 조판을 완전히 보증하지 않는다.

한글 변환자가 자동으로 남긴 **`lastsaveby`**는 파생본에서 공개 변환 표시로 익명화했다. 기존 **`creator`**는 별도 메타데이터이며 전부 비어 있거나 익명화됐다고 주장하지 않는다. 원본 기관 파일의 바이트·SHA·공식 URL은 변경하지 않았다. 사용자가 입력하는 개인정보와 기존 원본의 제작자 정보, 변환 작업자의 프로필 정보는 구분한다.
