## 지역 접수 및 시행일 검증

새 `national-municipal-intake-reference`는 기관 원본에만 적용한다. 검토된 정확 프로그램·원본 SHA·시군구·공식 접수 페이지 SHA·직접 다운로드 URL·초기 신청 단계·대상 근거·조건문에 결속한다. Python 수입기와 TypeScript 공개 검증이 같은 기준을 적용하며 reference가 링크에서 소실되지 않는지도 검사한다. 기존 관할 판정을 전역 완화하지 않았다.

전국 공통 서식은 지역을 선택하지 않아도 보인다. 국가 사업의 지역 대안은 하나뿐이어도 선택한 지역 또는 일치하는 선호 지역에만 보인다. 기존의 단일 시도 접수 경로는 유지했다. 독립 검토에서 발견한 빈 지역 객체의 양언어 판정 차이를 수정해 null·미지정만 허용하며, 잘못된 빈 객체·배열·false·문자열·숫자를 거절한다.

증평 `1995491`의 API 메타 시행일2024-12-20은 바꾸지 않았다. 실제 현행 부칙과 군보13쪽의 시행일은2025-01-01이다. 정확 공포일·번호가 있는 메타 파일, 고정한 공식 HTML, HTML과 같은 본문, 실제 파일 바이트 SHA 및 부칙 인용을 검증한다. 이 법규는 이미 확인된 부칙 근거를 생략하거나 API 메타 날짜로 되돌려 통과할 수 없다. 다른 법규의 기존 메타 일치 기본 경로는 유지한다.

`rule-3211501`의 고시 전체 시행일2026-05-01과 서식 머리말 개정일2026-07-01도 구분했다. 같은 고시 부칙이 일부 안내의 지연 시행을 정한다. 모든 부분이 한 날짜에 개정됐다는 소급 해석은 하지 않으며, 국가 사업의 조건문에 두 날짜를 명시한다.
