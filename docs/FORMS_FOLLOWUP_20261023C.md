## HWP 작성과 검증

6개 HWP는 원본 SHA·전체 본문과 실제 한글 출력 10쪽을 확인했다. 작성용 변환도 10쪽 모두 원본과 본문·쪽 수·렌더 픽셀이 같음을 검증했다. 전체 검증된 변환은 2,492개·4,257쪽이며 런타임 검증을 통과한 작성 매니페스트는 1,218개다.

이번에 작성 매니페스트가 추가된 원본은 당진 금융동의서와 포천 미지급 청구서다. 당진 금융동의서는 현재 지원하는 입력칸이 1개이며 서명·동의 등 잠긴 부분은 직접 작성해야 한다. 모든 항목을 화면에서 완성할 수 있다는 의미로 집계하지 않는다.

당진 건강음료 통합서식은 열린 73칸 중 다른 서비스 칸이 49개여서 정확한 원본 SHA에 한정해 화면 작성을 차단했다. 공식 HWP 다운로드와 검증된 변환본은 보존했다. 계룡·성남 원본은 지원하지 못하는 글꼴·칸 식별 등의 이유로 화면 작성이 열리지 않는다. 기존 변환 보류 원본 2개와 부산 중구 부분 승인 서식의 작성 보류도 유지했다.

프로덕션 빌드·타입 검사, 단위 검사 1,184개, Python 검사 277개, PC·모바일 통합 검사 126개를 통과했다. 통합 검사는 실제 원본 바이트·SHA, 조건 표시, 추가 사업자료 연결, 보류 서식 작성 차단과 HWP/HWPX 다운로드를 확인했다. 당진·성남 모바일 및 포천 PC 카드도 화면으로 확인했다.
