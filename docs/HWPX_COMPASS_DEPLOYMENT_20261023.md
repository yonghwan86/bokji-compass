# 복지나침반 운영 반영 인계 — 2026-10-23

운영 대상은 **https://bokji-compass.vercel.app/**, 저장소는 **yonghwan86/bokji-compass**다. 반영 PR은 [#61](https://github.com/yonghwan86/bokji-compass/pull/61)이다. 이 기록은 운영 전 검증이며 운영 배포 완료 기록이 아니다.

## 반영할 기능

혜택 상세에서 검증된 **2,509개 HWPX**를 바로 내려받을 수 있다. 공식 HWP 원본도 함께 유지한다. 이 중 **1,508개 서식**은 브라우저에서 지원되는 칸을 채우고 작성본 HWPX로 받을 수 있다. 원문과 입력 위치를 검토해 기존 1,219개를 유지하고 289개·4,539칸을 추가했다.

모든 칸이 자동으로 완성되는 것은 아니다. 지원하지 않는 칸은 받은 작성본에서 보완하고, 서명·동의·담당자 확인은 원문 안내에 따라 직접 처리한다. 입력값은 브라우저 메모리 안에서만 사용하고 서버·MCP·AI로 보내지 않는다. 기존 공통 HWPX 2종의 작성기는 별도로 유지한다.

양식이 연결된 사업은 2,564건, 공개 원본은 2,844개다. 수록 상세 사업자료 23,578건과 서식 수를 혼동하지 않는다. 전체 수집·재매칭·문자 폭 검토의 상세 근거는 [HWPX 기능 기록](HWPX_WRITING_20261023.md)에 있다.

## 운영 코드와 통합한 검증

- 운영 `main`의 `110be2e4`까지 반영했다. 기존 홈·검색·상세·가족 질문·음성 기능과 복지 데이터 505개 파일을 유지했다.
- Next.js 프로덕션 빌드와 TypeScript 통과. 전체 단위 **1,506개 통과**.
- 브라우저 전체 **652개 조건 중 649개 통과, 3개 조건부 미실행**. 최초 전체 실행의 2개 실패는 예시 결과가 저장되기 전에 다음 화면으로 이동한 테스트 준비 문제였다. 실제 결과 화면이 표시된 뒤 이동하도록 수정하고 해당 파일 13개를 다시 통과시켰다. 제품 코드는 이 보완으로 변경하지 않았다.
- 미실행 3개는 데스크톱에 해당하지 않는 터치 시험 1개(모바일에서는 통과), 별도 음성 파일·API 설정이 필요한 실제 OpenAI 음성 연결 시험 2개다. 모의 음성 흐름과 기존 인터페이스 검사는 실행했다.
- 자료 작업 저장소의 Python **375개**, HWPX 관련 PC·모바일 **288개**도 통과했다.
- PC·모바일에서 받은 작성본 12개는 쌍별 바이트가 같았다. 고유한 6개 신청서 9쪽을 실제 한글에서 열어 전체 쪽을 확인했고, 입력 위치·날짜·선택 표시·서명/동의/기관란 보존 및 쪽 수를 대조했다.
- 원본 2,844개, 변환본 2,509개, 입력 manifest 1,508개, 다운로드 샤드 256개와 Git 바이트·해시를 확인했다. 설치 글꼴 바이너리는 저장소에 넣지 않았다.

Windows에서 기존 메뉴판 테스트가 슬래시 하나에 의존하던 문제는 테스트 경로 정규화로 보완했다. 실제 사업 번들을 재수집하거나 재생성하지 않았다.

## 실행 및 운영 반영

로컬 확인은 다음 순서로 할 수 있다.

```powershell
npm ci
npm run build
npm run start -- -p 3232
```

`http://localhost:3232/forms`에서 HWPX 내려받기 수와 화면 작성 수를 각각 볼 수 있다. 기능 확인용으로 `/p/g41280.gov24-394000000111`의 신청서 영역에서 HWP 원본·HWPX 받기·화면 작성을 확인할 수 있다.

현재 연결된 GitHub 계정은 운영 저장소의 READ 권한만 갖는다. 운영 관리자가 PR #61을 검토·병합해야 운영 `main`의 기존 Vercel 배포 연결로 반영할 수 있다. 배포 설정과 운영 `main`은 이 작업에서 직접 변경하지 않았다. 자료 작업 저장소 `dlrmsals1425-dotcom/bokji`의 PR #12만 병합해서는 이 운영 주소가 갱신되지 않는다.

병합 후에는 운영 주소의 `/forms/writing/v1/downloads.json`에 2,509개, `/forms/writing/v1/index.json`에 1,508개가 제공되는지 확인하고, 혜택 상세에서 실제 HWPX 및 작성본을 받아 확인해야 한다. 운영 배포 성공 여부는 이 절차를 마친 뒤 별도로 판단한다.
