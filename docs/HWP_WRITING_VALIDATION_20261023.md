## 실제 한글 출력

공개 HWP 2,481개는 원본과 변환본의 전체 텍스트·한글 쪽수·모든 페이지 픽셀을 비교했다. 모아찍기가 적용됐던 28개는 검사 인쇄만 한 쪽씩 출력하도록 바꾸어 다시 비교했다. 원본의 저장된 인쇄 설정과 바이트는 변경하지 않았다.

가상 정보로 생성한 장수축하금 신청서·위임장, 좁은 칸의 `W` 최대 너비 시험, 후반 섹션의 신청인 동의서, 선택 표시를 실제 한글에서 다시 열었다. 원본과 같은 1·1·2·1쪽을 유지했다. 기존 공통 HWPX 브라우저 다운로드도 각각 4·3쪽으로 열어 확인했다. 이 최종 작성본 6종의 **전체 12쪽**을 렌더하고 육안으로 확인했다. 실제 개인정보는 사용하지 않았다.

빈 서식 변환의 전수 검사와 대표 작성본 검사는 다른 범위다. 모든 입력 조합과 다른 기기의 대체 글꼴까지 인쇄 검증한 것으로 해석하지 않는다. 그림·일부 개체는 브라우저에서 표시하지 못하지만 생성 파일과 공식 원본에서는 보존한다.

## 원본·개인정보 보존

공식 HWP의 ID·경로·바이트·SHA·공식 URL은 유지했다. 작업자가 한글 변환 시 자동으로 남긴 `lastsaveby`만 작성용 파일에서 익명화했으며, 본문·스타일·리소스의 압축 해제 후 바이트는 변경하지 않았다. 원본 다운로드는 익명화하거나 덮어쓰지 않았다. Git에 넣은 변환본 2,481개도 Git blob을 읽어 실제 크기·SHA를 다시 비교했다.

작성기는 공개 빈 파일만 읽고 입력 처리를 브라우저 메모리에서 수행한다. 작성 내용을 서버·MCP·AI에 전송하거나 전자서명·접수를 대신 수행하지 않는다. 기관 검토표·대장, 서명·동의 표시를 일반 입력으로 오인한 실제 사례는 잠금과 회귀 검사로 보완했다.
