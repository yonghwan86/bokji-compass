# 수록 복지자료의 출처와 집계 기준

현재 커밋된 자료를 기준으로 설명한다. 모든 제도를 새로 수집했거나 오늘의 자격·접수 상태를 확인했다는 뜻은 아니다. 사이트의 `/about#sources`에서 같은 집계와 공식 제공기관 링크를 볼 수 있다.

## 자료 수와 사업 수

- 상세 자료 ID는 **23,578건**이다. 지역에 배치된 자료 건수이며 전국 복지제도의 총 가짓수가 아니다.
- 중복 통합 후 사업자료는 **23,575건**이다. 같은 복지로 사업 3건이 인천 영종구·제물포구에 각각 배치되어 상세 자료가 3건 더 많다.
- 지역 연락처 등을 담은 **지역 운영 정보 2,359건**은 별도 자료다. 위 숫자에 더해 전체 복지 수로 표시하지 않는다.

| 출처 | 이 출처를 가진 상세 자료 | 원천과 수집 경로 |
|---|---:|---|
| 정부24 공공서비스 혜택 | 9,336건 | 행정안전부 공공서비스 API의 목록·지원조건·상세. [공공데이터포털 제공 설명](https://www.data.go.kr/data/15113968/openapi.do) |
| 복지로 | 5,232건 | 한국사회보장정보원 [중앙부처 API](https://www.data.go.kr/data/15090532/openapi.do)·[지자체 API](https://www.data.go.kr/data/15108347/openapi.do), 기존 복지로 색인 보강 자료 |
| 통합돌봄 서비스 메뉴판 | 10,218건 | 선행 대시보드가 수집한 `policies.csv`를 상속. 원출처는 [보건복지부의 시도별 메뉴판](https://www.mohw.go.kr/menu.es?mid=a60600000000)이며 서로 다른 문서 주소 230개·게시판 17곳과 연결 |
| 핵심 복지 100선 | 100건 | 운영자가 정리한 요약. 독립적인 공식 API가 아니며 원문 URL이 없는 항목도 있음 |
| 개별 확인 자료 | 3건 | 건강보험공단·수원시 등의 공식 안내로 개별 등록한 자료. 출처 화면에 해당 안내 링크를 제공 |

한 자료에 여러 출처가 있을 수 있다. 표의 합은 **24,889건**이고, 출처가 두 종류 이상인 자료는 **1,263건**이다. 표를 더한 숫자를 전체 복지 수로 쓰지 않는다. 두 종류인 자료 1,215건, 세 종류인 자료 48건이다.

## 날짜와 주소의 한계

정부24의 2026-10-02는 자료에 남은 수집 기록이다. 복지로의 2026-10-06은 선행 목록 캐시의 수정시각에서 가져온 기록이며 전체 원문을 그날 다시 수집한 증거는 아니다. 통합돌봄의 2026-10-01도 선행 수집본을 읽을 때 부여한 날짜다. 현재 사업 번들의 생성 시각은 2026-10-08T14:57:47.456Z다.

복지로의 출처 표기 5,271개 중 461개는 `2026`처럼 연도만 적힌 기준값이다. 이를 누락 날짜로 버리거나 정확한 최종수정일로 바꾸지 않는다. 나머지 4,810개에는 날짜까지 기록돼 있다.

원문 URL이 하나 이상 기록된 상세 자료는 **23,528건**, 하나도 없는 자료는 **50건**이다. 주소 없는 50건은 100선 요약만 출처로 남은 자료다. 100선 출처 표기 자체는 100개지만 나머지 50개는 병합된 다른 출처의 주소가 있으므로 구분한다. 기록된 모든 주소의 현재 접속 가능 여부와 모든 제도의 현행성은 전수 재검증하지 않았다.

## 신청서 자료는 별도 집계

현재 공개 다운로드 원본 **2,799개**, 하나 이상의 원본이 연결된 사업자료 **2,535건**, 사업–서식 연결 **3,523건**이다. 원본 하나가 여러 사업에 쓰일 수 있고, 한 사업에 신청서·위임장·동의서가 함께 연결될 수 있다. 이것도 복지 가짓수와 같은 단위가 아니다. 최신값은 `public/forms/v1/coverage.json`을 기준으로 한다.

HWP 원본을 작성용 HWPX로 변환한 수와 화면에서 입력할 수 있는 수는 다시 별개다. 해당 값은 `public/forms/writing/v1/index.json`에 기록하고, 원본 다운로드를 작성용 변환본으로 바꾸지 않는다.

## 재생성

`npx tsx scripts/build-data-provenance.ts`는 현재 상세 조각 256개와 집계 파일을 읽어 `src/lib/data/dataProvenance.json`을 생성한다. 원천 API 재수집이나 사업 번들 재생성을 실행하지 않는다. 서식 연결 자료를 갱신한 뒤에도 이 명령으로 출처 화면의 서식 수를 다시 맞춘다.
